# save-conversation（Codex Skill）
一个给 [Codex](https://openai.com/codex) 使用的「对话归档」技能：把有价值的 AI 对话一键存成 Markdown + Word，按主题自动归档。

它解决什么问题

能工智人每天和 AI 产生大量高价值对话：PRD 思路、竞品分析、决策推理、学习笔记……
但这些内容常常「聊完就散」——要么忘了存，要么散落在不同地方，找起来很费劲。

这个 Skill 用一句口令 `【生成文档】` 解决「存」的动作，用「主题文件夹 + 自定义命名」解决「整理」的动作，让对话沉淀成为你的个人知识库。

## 核心能力

- 📁 **一键归档**：`【生成文档】` 把当前对话同时存成 `.md` + `.docx` 两份（Markdown 给 AI/机器用，Word 给人读）。
- 🗂 **按主题归类**：根据对话主题自动建子文件夹，同名主题自动合并，不覆盖。
- ✏️ **自定义命名**：`【生成文档】周会纪要` 用你起的名字；不填则默认用「提问前 10 个字」。
- 🔀 **随时切换存储位置**：`【切换存储位置】[1.文件夹名=..] [2.路径=..]`，一个对话里也能切换不同主题的存储目录。
- 🧭 **零基础上手**：首次使用有欢迎引导；`【存档帮助】` 随时可查速查卡；口令打错会温柔纠偏。

## 快速上手（10 秒）

1. 首次使用，告诉它存哪里：
   ```
   存到桌面，文件夹叫「我的笔记」
   ```
2. 以后存档：
   ```
   【生成文档】              → 默认命名（提问前 10 字）
   【生成文档】周会纪要       → 自定义命名
   ```
3. 想换存储位置：
   ```
   【切换存储位置】[1.文件夹名=产品调研] [2.路径=/Users/xxx/Desktop]
   ```
4. 忘了命令：
   ```
   【存档帮助】
   ```

## 命令速查

| 命令 | 作用 |
|------|------|
| `【生成文档】` | 存档（默认：提问前 10 字命名） |
| `【生成文档】自定义名字` | 存档（用自定义名字） |
| `【切换存储位置】[1.文件夹名=..] [2.路径=..]` | 换存储位置 |
| `【存档帮助】` | 查看本速查卡 |

## 归档结构

```
<存储根目录>/

    ├── <文档名>.md
    └── <文档名>.docx
```

## 安装

把本文件夹放进 Codex 的全局技能目录：

```bash
cp -r save-conversation ~/.codex/skills/
```

新开一个 Codex 对话即可生效。首次使用时按提示配置存储位置。

## 设计理念（产品视角）

- **用示例代替说明书**：欢迎语只讲 2 步，带可复制的例子。
- **用即时提示代替记忆**：每次保存后只补一个小技巧，渐进教学。
- **用容错代替报错**：口令打错温柔纠偏，格式不完整给示例式修复。
- **默认值 + 显式覆盖 + 显式切换**：零配置也能用，想要自定义也随时可以。

## 适合谁

- 每天和 AI 大量对话、想把内容沉淀成个人知识库的人。
- 希望「存档不打断思路」的产品经理 / 知识工作者。
